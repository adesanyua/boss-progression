# Boss Progression

A NeoForge mod for Minecraft **1.21.1** that adds configurable boss encounters, progression requirements, rewards, and a two-page Boss Journal.

## Features

- Progress through Evoker, Elder Guardian, and Wither encounters.
- Customize boss names, health, armor, damage, equipment, and entity NBT.
- Configure unlock requirements, owner-specific rewards, and manual progression resets.
- Place encounters in existing structures, custom NBT buildings, or biomes.
- Watch defeated encounters gradually collapse into small ruins while protecting terrain and player edits.

Editable configs with English hints are generated automatically on the first launch in `config/bossprogression/`. Apply changes with `/reload`; mob settings apply to future spawns.

See [Configuration](docs/CONFIG_FILES.md) and the [test matrix](MVP9_TEST_MATRIX.md) for details and current limitations.
